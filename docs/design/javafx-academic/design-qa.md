# JavaFX 教务设计验收记录

## 验收范围

2026-09-06 使用 `AcademicScreenshotTest` 向生产 JavaFX 视图注入固定、脱敏的类型化教务数据，检查学生选课与课表、管理员培养方案与排课、教师成绩册，以及加载、空结果和可重试错误状态。截图测试不启用生产 mock 模式，也不连接数据库。

## 自动化覆盖与边界

截图夹具包含长课程名、满班、时间冲突、排课冲突、未录成绩、空结果和可重试错误。自动化同时覆盖权限路由、培养方案版本、排课发布、原子换班、成绩发布完整性、协议解码和注销后的迟到回调抑制。

截图只能证明固定字体与上述窗口尺寸下的布局。迁移 `014_academic_curriculum_javafx.sql`、真实 MySQL 数据、两个客户端同时抢占名额和网络中断后的状态确认仍需按 `docs/academic-management.md` 手工验收。
