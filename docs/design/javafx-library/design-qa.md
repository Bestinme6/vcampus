# 图书馆 JavaFX 设计与检查记录

## 设计结果

图书馆已从 Swing 兼容页升级为原生 JavaFX + CSS，并保持现有 C/S 架构。读者页使用书封卡片、状态标签和清晰的主次操作；详情页集中展示馆藏和借阅统计；预约页明确说明提醒不锁书、不排队。图书管理员使用独立的书目、实体馆藏、借还办理和借阅查询工作区。

## 响应式规则

- 宽内容区显示三列书目卡片，窄内容区自动收为两列。
- 检索条件使用可换行工具栏，最小窗口下搜索按钮不会被裁切。
- 管理员书目表格在 1000px 窗口内压缩列宽，仍保留“借出”和“借阅次数”；数据较多的馆藏与借阅表允许水平滚动。
- 长页面统一置于滚动容器，操作按钮保留完整中文标签。
