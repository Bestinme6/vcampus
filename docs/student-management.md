# 虚拟学籍管理设计

## 功能范围

- 学生查看本人学籍档案；
- 学生修改本人电话、邮箱和地址；
- 学籍管理员按学号、姓名和状态分页查询；
- 超级管理员通过“账号管理”事务创建学生登录账号和档案；
- 学籍管理员维护联系方式和学籍状态；
- 学生和管理员查看学籍状态变更历史；
- 超级管理员和以教师为基础身份的学籍管理员拥有学籍管理权限。

## 数据库结构

| 表 | 作用 |
| --- | --- |
| `departments` | 学院基础数据 |
| `majors` | 专业及所属学院 |
| `administrative_classes` | 行政班、所属专业和入学年份 |
| `student_profiles` | 学生个人档案和当前学籍状态 |
| `student_status_history` | 不可覆盖的学籍状态变更记录 |

已执行过旧版数据库脚本的环境，可以重新执行最新 `database/schema.sql`。脚本使用 `CREATE TABLE IF NOT EXISTS`，只会补建新的学籍表；随后重新执行 `database/seed.sql` 添加演示学院、专业和班级。

## 服务动作

| Action | 权限 | 说明 |
| --- | --- | --- |
| `student.getSelf` | 学生 | 查询当前账号关联的学生档案 |
| `student.get` | 学籍管理员、超级管理员 | 查询指定学生的完整档案 |
| `student.search` | 学籍管理员、超级管理员 | 分页查询学生 |
| `student.update` | 学籍管理员、超级管理员 | 修改姓名、院系班级和联系信息 |
| `student.updateContact` | 本人或学籍管理员 | 修改电话、邮箱和地址 |
| `student.changeStatus` | 学籍管理员、超级管理员 | 变更学籍状态并写历史 |
| `student.statusHistory` | 本人或学籍管理员 | 查询最近 20 条状态记录 |
| `student.referenceData` | 学籍管理员、超级管理员 | 加载学院、专业和班级下拉数据 |

所有动作都要求有效的服务端会话令牌。客户端隐藏按钮不是授权依据。

## 状态流转

- 在读 → 休学、退学、毕业；
- 休学 → 在读、退学；
- 退学和毕业为终态，不允许恢复；
- 选择与当前状态相同的状态不会重复写历史。

## 本机验收步骤

1. 在 MySQL Workbench 重新执行最新 `database/schema.sql` 和 `database/seed.sql`；
2. 重启 `ServerMain`，再启动 `ClientMain`；
3. 使用超级管理员登录，点击左侧“账号管理”；
4. 点击“创建账号”，选择学生身份、学院、专业和班级并设置临时密码；
5. 退出管理员账号，使用新学生的学号和初始密码登录；
6. 按提示强制修改临时密码，再验证“我的学籍”、联系方式修改和状态历史；
7. 重新使用管理员账号测试查询、状态变更和权限限制。
