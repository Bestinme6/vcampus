## 设计与验证记录

`docs/design/` 保存 JavaFX 页面设计、视觉基线和阶段性 QA 记录。截图与日期反映对应验证时点，最终功能状态仍以需求与实现状态、当前代码和测试结果为准。

## 历史开发记录

`docs/superpowers/` 保存开发计划和实施记录。目录中的分支名、worktree 路径、待办项及阶段状态都是当时快照，不应据此判断当前分支、启动方式或交付完成度。

## 文档维护约定

- 功能状态变化时同步更新 `requirements.md`。
- 启动、环境变量或数据库准备方式变化时更新 `delivery-guide.md`。
- 测试命令或验收口径变化时更新 `testing.md` 与相关模块文档。
- 演示顺序、账号角色或预置数据变化时更新 `demo-guide.md`。
- 不在文档中提交数据库密码、演示密码、令牌或真实个人数据。
