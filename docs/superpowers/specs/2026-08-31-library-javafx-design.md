# 图书馆 JavaFX 升级与归还提醒

用户已确认整体蓝白 JavaFX 图书馆方案，并接受“正常归还时通知所有有效预约学生，不排队、不锁书”。保留 Java 21、Socket / MessageCodec / MySQL 三层 C/S；客户端不得连接数据库。保留已有其他模块与未提交的论坛升级。

## 页面

读者图书检索采用宽搜索区、分类和排序控件、带排版封面的图书卡片、可借与已借出状态、借阅次数；封面用真实书名和分类排版，不冒充出版社封面。详情显示馆藏、作者、出版信息及借阅/预约操作。我的借阅保持续借和正常归还；学生增加我的预约，可取消等待中的提醒。教师保留借阅功能，本轮预约仅面向学生。

管理员页面重做为 JavaFX 表格和表单，保留书目新建/编辑/停启、馆藏创建/状态管理、借还办理与借阅查询。不删除已有业务功能。借还办理保留身份与条码预览、正常/破损/遗失归还和原因字段。

## 预约

- 按书目预约。只要启用书目有 ON_LOAN 馆藏即可申请，不要求可借数为零；DAMAGED、LOST、WITHDRAWN 不算已借出。
- 已借有同书目未归还馆藏的学生不能预约；同一学生同一书目最多一条 WAITING 预约。允许取消与后续重新预约。
- 正常归还使馆藏恢复 AVAILABLE 时，在归还事务内通知该书目的所有 WAITING 学生并标记 NOTIFIED。破损、遗失归还不发可借提醒。没有优先借阅权或取书保留期。
- 成功借到该书目时取消本人尚在等待的提醒，避免继续收到无意义通知。
- 所有身份和记录归属由服务端会话决定。归还重试、重复预约与并发归还不得产生重复通知或重复有效预约。
- 状态 WAITING / NOTIFIED / CANCELLED；我的预约分页显示书目、创建时间、状态和通知时间。通知可跳到该书目详情。

## 排序与兼容

图书检索和管理书目列表支持 CODE_ASC/DESC、TITLE_ASC/DESC、CATEGORY_ASC/DESC、BORROW_COUNT_ASC/DESC。分类同时支持筛选。借阅次数为累计成功借阅记录条数，续借不另计；按书目汇总其馆藏历史，不新增易失同步的计数列。服务端排序后分页，以 book id 稳定处理同值。

旧 12 字段 catalog RowCodec 行不变，追加独立元数据 row.N.onLoanCopies / row.N.borrowCount；详情额外返回 onLoanCopies / borrowCount。旧调用不传 sort 时保持原顺序。新预约列表为 7 字段行：id, bookId, catalogCode, title, status, createdAt, notifiedAt。

新增 library.reservation.create/cancel/my 与通知类型 LIBRARY_RESERVATION_AVAILABLE、目标 LIBRARY_CATALOG。迁移单独新增预约表与通知约束，保留现有数据，不在用户本机自动执行数据库迁移。
