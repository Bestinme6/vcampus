# JavaFX 校园门户首轮迁移

用户已确认：保留三层 C/S，使用 JavaFX 重做界面；采用第一组登录布局、第二组“我的校园”布局，并将登录插画替换为东南大学大礼堂的浅蓝线稿。2026-08-31 用户确认融合效果稿。

## 范围

本轮提供可运行的 JavaFX 登录、首次强制改密、工作台导航、我的校园和退出登录。保留现有 Swing 业务模块，通过 SwingNode 嵌入同一 JavaFX 窗口，不重写银行、商店、教务等服务。旧 Swing 启动入口保留为显式回退选项。不得声称所有模块均已迁移为 JavaFX。

## 设计与数据

- 登录左侧为大礼堂插画与真实文字覆盖层，右侧为账号密码表单；连接设置放入可展开区域，保留服务器地址、端口和测试连接。环境变量优先，无密码持久化。
- 我的校园为浅色侧栏、身份信息、当前周日期条、课程时间线、待办列表和紧凑汇总。
- 学生读本人档案、本人课表；教师读本人教师档案和授课课表；超级管理员显示管理入口，不请求学生或教师本人档案。
- 课程按日期所属学期、星期及教学周过滤。现有数据库存有学期起止日期，服务端参考数据新增独立 startDate/endDate 字段，保留原 term.N 三字段编码，兼容旧客户端。旧服务端没有日期时提示无法确定当日课程，不能猜测学期。
- 系统只定义节次，未提供学校作息时间。因此真实页面显示“第 n—m 节”，不得把效果稿演示钟点当真实作息。
- 借阅待办来自实际未归还记录（含逾期），订单待办来自真实已发货订单，余额来自银行接口；失败显示不可用，不能显示伪造的零值。加载概览不得执行充值、下单或确认收货。
- 日期按 Asia/Shanghai 计算，周条跨月/跨年正确；选择日期更新课表，刷新重新读取服务器。

## 架构与生命周期

- Java 21；JavaFX 21 系列；保留 MessageCodec 长度前缀二进制协议。客户端不得连接 MySQL。
- JavaFX UI 只在 FX Application Thread 更新；Swing 工厂、模块激活和销毁在 EDT；请求在后台执行器运行。
- 异步结果使用请求代次与会话代次避免注销、关闭及快速切换日期后的旧结果回写。
- 首次改密前不创建校园主页、不发业务请求；取消改密撤销会话。关闭或注销停止轮询、清理 UI 与会话引用。
- Swing 模块实例按会话缓存；消息深链复用业务模块；返回工作台在同一窗口完成。
