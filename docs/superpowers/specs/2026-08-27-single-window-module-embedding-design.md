# VCampus 单窗口模块嵌入设计

## 目标

登录后的 `MainFrame` 作为唯一主窗口。用户从工作台打开业务模块时，模块显示在左侧导航右侧的主内容区，不再创建独立业务窗口。成功、失败、确认以及短小录入表单仍可使用模态对话框。

第一批只迁移图书馆，用它验证主内容路由、模块复用和消息深链；学籍、教师与教务在后续批次按同一模式迁移。

## 设计边界

- 只修改 `vcampus-client` 与相关文档。
- 不修改 Socket 协议、服务端业务、数据库结构和权限规则。
- 网络请求继续在后台线程执行，Swing 组件更新继续回到 EDT。
- 图书馆现有页签、权限差异和弹窗交互保持不变。
- 同一个登录会话只创建一个图书馆模块实例；重复进入时复用该实例。

## 主内容路由

新增 `MainContentHost`，封装 `CardLayout`、已注册页面和当前页面名称。固定页面（工作台、账号管理、消息中心）在主窗口构造时注册；业务模块通过工厂在第一次访问时惰性创建。

路由必须支持：

- 显示已经注册的页面；
- 首次显示业务页面时调用一次工厂并注册；
- 后续显示同名页面时复用原组件，不再调用工厂；
- 暴露当前页面名称，便于回归测试与后续导航状态扩展。

## 图书馆模块

新增 `LibraryModulePanel`，承载原 `LibraryFrame` 的标题、说明和全部权限化页签。它提供 `openMyLoans()`，供消息中心深链定位“我的借阅”。

`LibraryFrame` 保留为薄兼容包装器，内部只挂载 `LibraryModulePanel`，避免潜在外部调用突然失效；工作台和消息中心不再创建它。

图书馆内容区提供“返回工作台”按钮。返回只切换主内容卡片，不销毁图书馆面板，因此页签和筛选状态可保留。

## 导航行为

- 点击工作台“书”卡片：主内容区切换到图书馆。
- 重复点击：复用同一图书馆面板。
- 点击图书馆“返回工作台”：回到工作台并恢复工作台导航选中样式。
- 从图书馆通知点击“查看我的借阅”：关闭通知详情后切换到嵌入式图书馆，并选中“我的借阅”。
- 无借阅权限时，消息深链继续显示“该页面当前不可用”。

## 对话框规则

以下交互继续使用对话框：成功或失败反馈、危险操作确认、图书详情、短小的新建/编辑表单。模块检索、列表、页签和长期浏览内容必须留在主内容区。

## 验收标准

1. 点击工作台图书馆卡片后，主窗口数量不增加，右侧显示图书馆。
2. 图书馆权限页签与迁移前一致。
3. 返回工作台后再次进入图书馆，仍是同一个模块实例。
4. 图书馆通知可直接定位嵌入式“我的借阅”。
5. 操作确认、成功和失败提示仍以对话框显示。
6. `mvn clean verify` 全部通过。
