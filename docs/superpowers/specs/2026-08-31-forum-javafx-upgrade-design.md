# 论坛 JavaFX 升级设计

## 状态与范围

用户已确认升级范围与浅蓝白色视觉方向，并强调 UI 美观为核心验收项。本文件将其细化为待审核规格；不是已经实现的功能清单。

本轮包含原生 JavaFX 论坛首页、详情、发帖、个人内容与管理界面，以及评论规则修复、点赞、收藏、回复、热榜、管理员公告。保留三层 C/S、Java 21、现有 Socket 协议和消息中心。不做匿名、图片上传、投票、聊天或全站 UI 重写。

## 视觉与布局

以用户提供的论坛截图为参考，沿用现有校园门户的字体、蓝色体系与 Feather 图标。使用独立 forum.css，并将样式限定在论坛根节点，避免改变登录、银行等模块。

- 页面背景 #F4F7FC，卡片白色，主文字 #172139，辅助文字 #64748B，边框 #DCE5F2，强调蓝 #2F5FCB。
- 按钮文字统一黑色 #111111；主要按钮用浅蓝 #DCE8FF，悬停加深背景，边框和图标辅助区分主次，不沿用全局白字 primary 类。
- 页面标题 26px，帖子标题 20px，正文 15px，辅助文字 13px；采用现有 Microsoft YaHei UI 字体回退。
- 页面内边距 28px，分栏间距 24px，卡片间距 16px，卡片内边距 22px，圆角 12px；以细边框为主，不堆叠强阴影。
- 延续校园客户端主导航，不再添加截图中的第二套品牌侧栏。论坛局部导航为“论坛首页 / 我的帖子 / 我的收藏 / 内容管理”，管理项按角色显示。
- 论坛可用内容区宽度达到 1080px 时显示右侧 280px 信息栏，主列自适应；不足时隐藏信息栏，公告保留独立入口。搜索和操作区换行，不挤压正文。
- 以 1440×900、1280×800 和 Windows 125% 缩放场景检查。正文不横向滚动，长标题和长姓名可换行；页面不出现双重纵向滚动。

## 首页

顶部为“校园论坛”、简短副标题、搜索框与“发布帖子”。下方为局部导航、最新 / 热门 / 精华切换、板块筛选，再到帖子列表。

帖子卡片依次展示板块和状态标签、标题、最多两行摘要、作者与发布时间、点赞与评论数量。学院和年级没有真实数据时不显示，不使用样例身份填充。置顶与精华分别使用浅金、浅绿标签。卡片有轻微悬停反馈；点赞、收藏等独立按钮不能误触打开详情。

右栏为校园公告、今日热榜、社区提示。公告和热榜均读取服务器；无记录展示明确空状态，不使用截图内的固定数据。列表使用每页 20 条分页，保留筛选和滚动位置。

最新按创建时间、ID 倒序；精华仅筛选正常精华帖；热门按正常帖子当前点赞数 + 正常评论数×2 降序，再以创建时间、ID 倒序打破平局。置顶仅在首页列表内优先，不改变个人列表。今日热榜统计 Asia/Shanghai 当日产生且当前有效的点赞、正常评论，按点赞数 + 评论数×2 排名前五；无当日互动则显示暂无热榜，不伪称实时推送。

## 帖子详情与发帖

详情采用单一阅读主列：返回入口及板块、标题、作者时间、正文、点赞收藏操作条、评论区。不把“帖子详情”作为固定导航项。返回时恢复原列表位置和筛选。

评论卡片展示作者、时间、正文与轻量操作。点击回复，在输入区显示“回复某某”及取消入口。回复保持一层列表，显示回复对象，不做无限缩进。发布期间禁用重复提交，失败保留输入；成功后重新读取真实数据。

发帖采用同一窗口内的编辑页面，包含板块、标题、正文、字数提示、取消与发布。复用服务端长度校验，离开未提交内容前确认。只支持纯文本并保留换行，不渲染用户 HTML。

## 删除与审核规则

- 日常评论列表对所有角色仅返回 NORMAL，分页总数与显示范围一致。管理查询独立保留 NORMAL / HIDDEN / DELETED。
- 删除接口只允许作者删除自己的正常评论，包括管理员自己的评论。删除前二次确认，数据库保留软删除记录；不能通过旧客户端或直接 Socket 请求绕过作者限制。
- 管理员处理他人评论必须走 HIDE / RESTORE 流程，沿用原因校验、审核日志与消息通知。RESTORE 仅对 HIDDEN 有效，不恢复作者主动删除的评论。
- 已隐藏或删除的评论不能再回复。回复目标必须属于同一帖子；目标之后不可见时不向普通用户泄露原文，显示“原评论已不可见”，正常的回复自身仍可展示。
- 未选择评论、无权限、评论状态变化采用不同提示，不再一律提示“请选择自己发布的评论”。
- 内容管理使用明确中文状态、筛选和操作面板。根据选中记录状态启用操作；软删除记录可审阅但不可恢复。
- 本轮修复评论语义；帖子现有删除/审核流程保留，不扩展为全论坛物理删除。

## 新互动与通知

- 点赞与收藏按用户和帖子唯一；使用设置目标状态接口，而非盲目 toggle，重复请求不会重复计数。只能对可访问的正常帖子新增互动；可移除自己的既有收藏。
- 我的帖子仅查本人；可显示自己的正常、隐藏、删除记录及状态。不可访问记录不进入日常详情，展示不可用原因。我的收藏仅显示当前可访问帖子，数量与列表一致。
- 回复以可空 reply_to_comment_id 关联原评论，并记录实际回复对象。服务端验证归属、可见性、帖子锁定状态，不信任客户端提供的收件人。
- 保留新评论通知发帖人；回复通知被回复者。同一事件同一收件人只收一条，优先显示回复通知；不给操作者本人通知。
- 收藏属于私有行为，不通知作者。本轮点赞只更新计数，不增加逐次点赞通知，避免消息中心被淹没。
- 评论隐藏/恢复等现有管理通知继续保留。通知与业务写入在同一事务提交，失败不出现半成功；消息点击打开 JavaFX 帖子详情，评论不可用时给出提示。

## 公告

增加帖子公告标记，由论坛管理员、超级管理员在管理界面明确设置或取消，填写原因并记录审核日志、通知帖子作者。普通发帖者不能设置。只有正常且标记为公告的帖子进入公告栏，按公告设置时间倒序，最多三条，并可进入公告列表。

不将普通置顶帖自动变成公告；界面标记“管理员公告”，不以未经验证的“校方发布”身份背书。公告继续复用帖子详情，不另建独立发布系统。

## 实现边界

- common 增加互动/公告动作和必要协议字段；旧字段含义不变。新功能在缺少新服务端支持时显示可理解错误，不能静默返回假成功。
- server 承担权限、排序、分页、唯一性、事务及 JDBC；新增查询采用参数绑定。可见性判断不能仅依赖客户端。
- client 增加独立的论坛数据适配层、异步控制器、页面与卡片组件，复用 VCampusClient。业务控制不继续堆进 CampusApplication。
- JavaFX 门户的论坛导航与消息深链改为原生 JavaFX；其他模块继续保留 Swing 桥接。旧 Swing 论坛兼容新评论权限与提示，但本轮不为其复制所有新增互动界面。
- 所有网络请求在后台执行器，所有新 UI 更新在 FX Application Thread；保留请求代次和会话代次检查。切换页面、注销或关闭时丢弃过期结果并清理资源。
- database/schema.sql 合并新增表、字段、索引和通知约束，支持新库及现有库安全升级。seed.sql 可重复执行且兼容 Workbench safe-update 模式；不重置已有用户互动或业务数据。继续支持依次运行最新 schema、seed，不强迫用户逐个执行迁移脚本。
- 不改动现有无关工作区变更、不替用户启动正式服务端、不修改真实数据库或推送远端。

## 验收

- 权限测试覆盖普通人、论坛管理员、超级管理员，自己的/他人的评论，以及正常/隐藏/删除状态；普通查询中任何角色都不能读到隐藏和删除评论。
- 互动测试覆盖唯一性、幂等、并发计数、跨帖回复拒绝、不可见目标、锁定帖子禁止评论、通知去重和事务回滚。
- 查询测试覆盖搜索、筛选、分页、个人数据隔离、排序平局、今日跨日边界与空热榜。
- JavaFX 测试覆盖页面路由、返回位置、加载失败重试、失效会话、双击提交、消息深链与线程归属。
- 使用测试专用数据渲染首页、详情、发帖与管理页实际 JavaFX 截图，检查长文、空列表、错误和加载状态。对照参考图检查间距、字号、边框、对齐及缩放；不将效果图或网页截图当作 JavaFX 验收。
- 根目录 mvn clean verify；SQL 特有行为需要隔离 MySQL 验证，不能用 Maven/H2 成功替代真实 MySQL 结论。未进行的人工/数据库验证在交付时明确列出。
- 更新 docs/requirements.md 与运行说明。功能通过但视觉拥挤、裁切或不统一，仍不算完成。
