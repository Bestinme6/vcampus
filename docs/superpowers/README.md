# 历史开发记录

本目录保存需求拆分、实现计划和阶段性执行记录，用于追溯设计与开发过程。

其中出现的分支名、worktree 路径、本机目录、待办项、测试数量和“未合并/待实现”等状态均是文档编写时的快照，不代表当前项目状态，也不应作为启动、交付或验收说明。

当前信息请以以下文档为准：

- `docs/README.md`
- `docs/requirements.md`
- `docs/delivery-guide.md`
- `docs/testing.md`
- `docs/demo-guide.md`

历史记录原则上不回写为当前状态；需要修正当前交付信息时，应更新上述主文档和对应模块文档。
