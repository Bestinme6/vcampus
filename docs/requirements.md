# VCampus 需求基线

## 1. 项目概况

- 项目名称：基于 C/S 的虚拟校园系统（VCampus）；
- 项目性质：课程作业；
- 计划交付日期：2026 年 9 月 20 日；
- 界面语言：简体中文；
- 数据库：MySQL Server 8.0.44；
- 基础身份：学生、教师、超级管理员，且每个账号只能拥有其中一种；
- 学生或教师可以在基础身份上附加符合规则的业务管理员角色；
- 在线课堂不在本次交付范围内。

## 2. 技术约束

- Java 21、Maven 多模块工程；
- Swing 桌面客户端；
- Java Socket、多线程和输入输出流；
- MySQL 8.0.44；
- 三层 C/S：数据库 -> 应用服务器 -> 客户端；
- 客户端不得直接连接数据库；
- 网络和数据库操作不得阻塞 Swing 事件分发线程；
- 客户端与服务端使用 `MessageCodec` 二进制协议，不使用 Java 原生对象序列化；
- 数据库凭据通过环境变量提供，不写入源代码。

## 4. 角色与权限基线

| 角色 | 主要权限 |
| --- | --- |
| 学生 | 查询本人学籍；选退课、查课表与成绩；借还图书；购物；使用虚拟银行；使用论坛 |
| 教师 | 查看和维护本人教师联系方式；查询授课信息与学生名单；录入并发布本人教学班成绩；使用图书馆、商店、银行和论坛 |
| 超级管理员 | 独立基础身份；账号、角色和系统配置管理；访问六个业务管理模块 |
| 学籍管理员 | 修改、查询学生档案和学籍状态；账号及档案创建统一由超级管理员完成 |
| 教务管理员 | 课程、教学班、选课和成绩管理 |
| 图书管理员 | 图书、馆藏、借阅和归还管理 |
| 商店管理员 | 商品、库存和订单管理 |
| 银行管理员 | 虚拟账户、充值、冻结和流水查询；不得修改历史流水 |
| 论坛管理员 | 板块管理、帖子审核和违规内容处理 |

服务端必须在每次业务请求中校验会话和权限，不能只依赖客户端隐藏按钮。

角色组合还必须遵守以下规则：

- 学生和教师身份互斥，超级管理员不能再叠加其他角色；
- 学生只能附加图书管理员、论坛管理员；
- 教师可以附加学籍、教务、图书、商店、银行、论坛管理员中的任意组合；
- 教务、学籍、商店和银行管理员必须以教师为基础身份；
- 即使教师拥有全部六种业务管理员角色，也不具备超级管理员专属的账号和系统配置权限。

## 5. 默认业务约定

这些约定用于保证开发可以继续推进，后续可按课程要求调整：

- 学号：10 位数字字符串，例如 `2026000001`；
- 教工号：字母 `T` 加 7 位数字，例如 `T0000001`；
- 课程号：字母 `C` 加 6 位数字，例如 `C000001`；
- 图书条码：字母 `B` 加 9 位数字；
- 登录名默认使用学号或教工号，管理员使用独立账号；
- 初始密码必须在首次登录后修改；密码只以带盐哈希形式保存；
- 金额使用 `DECIMAL` 或 Java `BigDecimal`，不得使用浮点数；
- 银行、商店库存和订单变更必须使用数据库事务；
- 业务记录默认采用逻辑状态变更，关键流水与审计日志不得物理删除。

## 6. 非功能要求

- 演示环境下支持多个客户端同时连接；
- 常规请求应给出加载、成功或错误反馈；
- 数据访问使用参数化 SQL，防止 SQL 注入；
- 客户端断线、错误输入和数据库不可用时应有可读提示；
- 关键操作记录审计日志；
- 主要协议、权限和服务行为应有自动化测试。

## 7. 界面基线

参考用户提供的工作台和课表图片，桌面客户端采用：

- 全局白色背景、浅色卡片和深色正文，保证表格与按钮文字清晰；
- 蓝色作为主要强调色，浅蓝色作为选中和提示颜色；
- 登录后进入“工作台”，以模块宫格展示可访问功能；
- 登录后的主窗口采用单窗口内容区；业务模块在工作台右侧切换，成功、失败、确认和短表单继续使用模态对话框；
- 图书馆、学籍、教师档案、教务、论坛、银行和商店已采用嵌入式业务模块；工作台入口与消息中心业务深链复用对应模块实例；
- 论坛提供首页、帖子详情和管理员内容管理三张 Swing 页面；后台入口只对论坛管理员和超级管理员显示；
- 论坛通知支持来源筛选和指定帖子深链；关联帖子不可访问时给出可读提示并返回论坛首页；
- 银行提供账户首页、转账、本人流水，以及按权限显示的账户管理、充值与冻结、全量流水页签；冻结账户不能转账或消费，但仍能收款、退款和查询；
- 银行通知支持来源筛选并直达本人流水页；
- 商店提供商品列表、购物车、我的订单，以及按权限显示的商品管理和订单管理页签；发货通知直达“我的订单”；
- 工作台根据基础身份和附加角色显示“学/师、教、书、商、银、论”，学籍管理员教师显示七张卡片并支持滚动；
- 左侧导航适配桌面端，顶部显示当前页面、搜索入口和登录用户；
- 学生与教师课表采用星期一至星期日、每天 12 节的图形表格；
- 管理员排课通过课表格子选择时段，已占用且周次重叠的教师时间不可选择；
- 不照搬移动端尺寸与底部手势区，保持 Swing 桌面应用的键鼠可用性。
- 查询和刷新按钮统一使用浅色背景、深色粗体文字，避免系统外观导致文字对比度不足。
- 只有超级管理员在“工作台”下方看到“账号管理”，普通学生、教师及业务管理员均不显示；
- 账号管理提供学生/教师账号创建、角色分配、启停和密码重置，不提供删除及超级管理员创建功能。
